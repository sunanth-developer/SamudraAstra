# Samudra Astra

Official website for Samudra Astra — aquatic defence technology for the maritime domain.

Built with React, Vite, GSAP, Lenis, and React Router. The cinematic motion system from the previous site is preserved and retuned for the Samudra Astra brand.

## Run

```bash
npm install
npm run dev
```

Copy is capability-level. It does not describe fielded products, contracts, customers, or performance specifications.
